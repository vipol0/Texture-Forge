# Texture Forge

Лёгкий GUI-прототип для стилизации текстур на Rust.

## Возможности
- Открытие PNG, JPEG, BMP и WebP — кнопкой или перетаскиванием файла в окно.
- Сравнение «до / после» с перетаскиваемым разделителем; независимые зум и панорама в обеих половинах (колесо — зум, перетаскивание — панорама, двойной клик — сброс).
- Сравнение размера файла до/после (с процентом изменения) для выбранного формата экспорта.
- Пикселизация с выбором разрешения длинной стороны (пресеты) с сохранением пропорций и исходного размера.
- 3D-предпросмотр текстуры на модели в отдельном окне: встроенные куб, сфера и плоскость, а также импорт OBJ, GLB, glTF и FBX (кнопкой или перетаскиванием). Открытая текстура накладывается по UV-развёртке модели; вращение и панорамирование мышью, зум, автовращение, режим сравнения «исходник / результат» с перетаскиваемым разделителем, раздельный повтор U/V, смещение и поворот UV, режимы Repeat/Clamp, управляемое освещение, фильтрация Nearest/Linear, сохранение кадра в PNG и собственная история действий с отменой/повтором (Ctrl+Z / Ctrl+Shift+Z). Рендер выполняется в фоновом потоке с понижением разрешения во время взаимодействия, поэтому интерфейс не подвисает на тяжёлых моделях.
- Геометрия: ручной кроп с перетаскиванием рамки и маркеров (или точными значениями X/Y/W/H в пикселях), явный размер результата, режимы Fit / Fill / Stretch и фильтры Nearest / Lanczos. Кроп хранится в пресетах и применяется в пакетной обработке.
- Настоящая оптимизация палитры по содержимому изображения (Wu и K-means через `quantette`, в пространстве Oklab).
- Дизеринг: упорядоченный (Bayer 8×8), синий шум (64×64), Флойд–Стейнберг, Аткинсон, Джарвис–Джадис–Нинке (JJN), Стьюки, Бёркс и Сьерра; настраиваемая сила и serpentine-обход строк для диффузии ошибки.
- Расширенная цветокоррекция: яркость, насыщенность, контрастность, гамма, температура/оттенок, уровни (чёрная и белая точка), авто-контраст по гистограмме каждого изображения, интерактивный редактор кривых (клик — добавить точку, перетаскивание — изменить, правый клик — удалить), инверсия, ч/б и сепия. Кнопка «Сбросить цвет» возвращает все параметры к нейтральным.
- Отмена/повтор изменений параметров (кнопки и Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y).
- Пресеты: встроенные наборы («Пиксель-арт», «Ретро-текстура», «Постер», «Сглаженная») и сохранение собственных под именем. Пользовательские пресеты хранятся в JSON и восстанавливаются при следующем запуске.
- Пакетная обработка: очередь из отдельных файлов или всех изображений папки, выбор папки вывода, прогресс-бар, отмена и отчёт об ошибках. Исходники не перезаписываются.
- Экспорт в PNG, JPEG (качество настраивается) и WebP. Общая приписка к имени файла (например, `_stylized`) добавляется перед расширением при одиночном и пакетном сохранении.
- Альфа и JPEG: шахматный фон в предпросмотре показывает прозрачность; режимы «Сохранить» (оставить альфу), «Порог» (сделать альфу двоичной по заданному порогу) и «Залить фоном» (скомпоновать изображение с выбранным цветом). JPEG не поддерживает альфу, поэтому прозрачные пиксели при экспорте заливаются выбранным цветом фона.
- Стилизация, оценка размера и сохранение выполняются в отдельном worker-потоке, поэтому интерфейс не подвисает на больших изображениях. Быстрые изменения настроек объединяются дебаунсом, а устаревший рендер отменяется и не тратит CPU.

## Сборка

Установите Rust stable с https://rustup.rs/

Для сборки нужен C-компилятор: FBX-парсер `ufbx` собирается из C. На Linux достаточно `build-essential`, на macOS — Xcode Command Line Tools, на Windows — Visual Studio Build Tools.

### Запуск (текущая платформа)

```bash
cargo run --release
```

### Linux

Для eframe могут понадобиться библиотеки оконной системы и компилятор C/C++ (например, `build-essential`, `pkg-config`, `libx11-dev`, `libwayland-dev`, `libxkbcommon-dev`).

```bash
cargo build --release
```

Готовый бинарник: `target/release/texture-forge`.

### Windows

Приложение — один самодостаточный `.exe`; дополнительные DLL и vcredist не требуются.

**Сборка на самой Windows**

```powershell
rustup target add x86_64-pc-windows-msvc
cargo build --release
```

Готовый файл: `target\release\texture-forge.exe`.

**Кросс-компиляция из Linux (MSVC через `cargo-xwin`)**

Требуются `clang`, `lld` и `llvm-lib` в системе (пакет LLVM).

```bash
export PATH="$HOME/.cargo/bin:$PATH"
rustup target add x86_64-pc-windows-msvc
cargo install cargo-xwin
cargo xwin build --release --target x86_64-pc-windows-msvc
```

Готовый файл: `target/x86_64-pc-windows-msvc/release/texture-forge.exe`.

**Альтернатива — MinGW (GNU)**

```bash
rustup target add x86_64-pc-windows-gnu
sudo dnf install mingw64-gcc   # или соответствующий пакет mingw-w64
cargo build --release --target x86_64-pc-windows-gnu
```

CRT линкуется статически (см. `.cargo/config.toml`), поэтому дополнительные DLL не нужны.

## Пресеты и конфигурация
Пользовательские пресеты сериализуются в JSON:
- Linux/BSD: `$XDG_CONFIG_HOME/texture_forge/presets.json` (или `~/.config/texture_forge/presets.json`);
- macOS: `~/Library/Application Support/texture_forge/presets.json`;
- Windows: `%APPDATA%\texture_forge\presets.json`.

## Замечания
Это рабочий прототип. Обработка ошибок записи выполняется без panic (ошибки пакета собираются в отчёт), реализованы пресеты и пакетная обработка.

Палитра реализована на чистом Rust через crate `quantette` (без C-зависимостей): Wu и K-means для квантования. Все режимы дизеринга — собственные: упорядоченный Bayer, предвычисленный синий шум и диффузия ошибки (Флойд–Стейнберг, Аткинсон, JJN, Стьюки, Бёркс, Сьерра) с опциональным serpentine-обходом.

3D-предпросмотр работает на CPU в отдельном потоке рендера, а сохранение кадра — в ещё одном потоке, поэтому тяжёлый кадр или кодирование PNG не блокируют интерфейс: текущая текстура из окна предпросмотра накладывается на геометрию по UV-развёртке модели (для glTF учитываются выбранный материалом набор UV и `KHR_texture_transform`, для OBJ и FBX выполняется преобразование V в систему координат изображения). Если у части модели UV отсутствуют, для неё используется сферическая проекция. Во время вращения, зума и автовращения кадр рендерится в пониженном разрешении, а после остановки — в полном; устаревшие кадры отменяются. Встроенные текстуры, скелет и анимация импортируемых моделей не учитываются. FBX читается через `ufbx` и поддерживается в ASCII- и бинарном виде.

Формат WebP доступен, если включён соответствующий feature в `image`.

При режиме Fit поля заполняются прозрачным фоном. PNG и WebP сохраняют прозрачность (в режимах «Сохранить» и «Порог»), а JPEG компонует прозрачные пиксели с выбранным цветом фона.
